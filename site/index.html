01 Same model

No quieter reasoning, no shorter context, no skipped checks. The trade is wall-clock time.

02 One request at a time

Follow-ups, reviews, and subagent model calls share one gate. Their calls wait. They are not dropped.

03 Leaves the shell alone

Compile, tests, and file reads are not delayed. The wait happens before the model request is sent.

04 Not a cheaper call

Slow Mode does not make one request cost less, and it does not get around the limit.
