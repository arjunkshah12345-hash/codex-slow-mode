How it works

Spend the allowance across the reset.

Slow Mode reads the usage Codex already tracks and waits only until the next sustainable model request. A long test suite already counts. The shell is left alone.

Same model

No quieter reasoning, no shorter context, no skipped checks. The trade is wall-clock time.

One request at a time

Follow-ups, reviews, and subagent model calls share one gate. Their calls wait. They are not dropped.

This session only

Nothing is written to your saved config. Fast mode returns when you turn Slow Mode off.

The boundary

It chooses when. That is the product.

Slow Mode paces requests you were going to send. It does not make a call cheaper, and it does not get around the limit.
